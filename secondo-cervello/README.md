# Secondo Cervello di Matteo Bascetta

Questo sistema è il mio archivio personale di conoscenza, memoria e supporto alle decisioni.

Non è solo una raccolta di note. È un sistema che:
- ricorda cosa ho vissuto e deciso
- collega nuove informazioni con quelle passate
- rileva schemi, abitudini e rischi ricorrenti
- mi aiuta a decidere meglio nel tempo

## Come funziona

Ogni area della mia vita ha una cartella dedicata. Claude legge il contesto esistente prima di rispondere, propone dove salvare ogni cosa importante, e aggiorna gli schemi quando rileva pattern ripetuti.

## Aree del sistema

| Cartella | Contenuto |
|----------|-----------|
| `memoria/` | Fatti personali importanti da non dimenticare |
| `diario/` | Riflessioni, giornate significative, stati d'animo |
| `lavoro/` | Lavoro, carriera, obiettivi professionali |
| `trading/` | Trading, posizioni, strategie, risultati |
| `finanze/` | Budget, patrimonio, spese, investimenti |
| `salute/` | Salute, benessere, sintomi, abitudini fisiche |
| `casa/` | Casa, spese domestiche, logistica |
| `relazioni/` | Relazioni personali e professionali |
| `progetti/` | Progetti attivi, in pausa, completati |
| `decisioni/` | Log delle decisioni importanti prese |
| `documenti/` | Riferimenti a documenti rilevanti |
| `schemi/` | Pattern, abitudini, errori ricorrenti rilevati da Claude |
| `regole/` | Principi e regole personali che voglio seguire |
| `revisioni-settimanali/` | Revisioni settimanali evolutive |
